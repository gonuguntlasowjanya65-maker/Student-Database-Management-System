# 🎓 Student Database Management System Using Python

A simple and beginner-friendly **Student Database Management System** developed using only **Python**.
This project is designed to manage student records efficiently through a command-line interface. It allows users to perform basic database operations such as adding, viewing, searching, updating, and deleting student details.

The project is created for learning purposes and helps beginners understand how real-world management systems work using Python programming concepts.

---

# 📌 Features

✅ Add new student records
✅ View all student details
✅ Search student information by ID or Name
✅ Update existing student records
✅ Delete student records
✅ Simple and clean command-line interface
✅ Easy-to-understand Python code
✅ Beginner-friendly project structure
